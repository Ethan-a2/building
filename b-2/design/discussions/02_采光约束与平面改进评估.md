# 讨论记录02｜采光约束下的整体设计评估

记录日期：2026-09-20。来源：业主补充采光与东侧退让条件，并询问整体设计改进。

**状态：设计评估与待比较方向，尚未选定新平面。现有R1 Blender模型保留作为比较基线，不能当成本记录建议已落实的模型。**

## 1. 本轮新增的业主信息

| 信息 | 状态与解释 |
|---|---|
| 北侧确实采光不好 | 已确认的现场体验；具体邻房高度、距离、窗外遮挡仍需实测 |
| 东侧有0.5m预退让，便于开窗，但采光不好 | 已确认描述；0.5m是否在12.6m建筑宽度之外、是否为自有地、连续范围待确认 |
| 西侧为道路 | 既有条件；道路可提供侧向开敞条件，但不能直接认定西向采光、开窗、防火与入口许可已通过 |
| 南侧采光最好 | 本轮应优先分配给长期使用的生活空间 |
| 南侧中央入口部分空间被楼梯占用，感觉浪费 | 业主关注点；应比较南向资源占用、总公共面积、动线与搬迁成本，不只比较楼梯投影 |

**尺寸歧义：**原模型主体宽12.6m。若东侧0.5m退让在这一宽度之外，需补充实际用地总宽和边界；若包含在12.6m用地面宽内，原主体宽度需要重新确认，不能继续假定建筑净占12.6m。当前不擅自将主体缩为12.1m，也不将地块扩为13.1m。

## 2. 对原方案的总体判断

原方案具备经济、紧凑、两户独立和厨卫镜像的基础；适合继续深化。其主要弱点不是缺少装饰，而是**长期卧室全部在北侧、南向面积集中在客厅和公共楼梯、中部餐区较深、东侧湿区仅靠窄退让带采光通风**。

北侧采光差并不自动说明卧室不合规，但在采光、通风和邻距复核前，不应把四间北卧室都视为已经合格的长期居住房间。租赁用途也不能降低这个判断标准。

### 建议保留的优点

- 方正体形、规则开间、两层厨卫叠合，利于当地常规施工。
- 公共楼梯与分户入口，适合分期入住及出租。
- 分区阀表和明装检修路线，适合长期低维护成本。
- 指定合户连接口，减少以后拆改。
- 南院作为缓冲、采光与日常活动空间。

### 建议重点调整的弱点

1. 不再默认“所有卧室都放北边”，至少为每户安排一处可长期睡眠的南向空间。
2. 区分客厅、老人卧室、备用睡眠三种使用状态，不能靠同一块面积同时承诺独立客厅与独立卧室。
3. 减少中部纯交通和重复餐客空间，让起居空间与采光较好的南侧有直接联系。
4. 东侧厨卫按“弱自然采光、必须可靠排风”组织，不依赖扩大窗面积解决遮挡。
5. 比较楼梯位置，但每种位置都重新计算公共走道、平台、门厅和套内损失。

## 3. 南侧楼梯是否浪费

现参考楼梯间约2.3×5m，平面占用约11.5㎡，是墙参考范围的粗略投影，不是准确公摊面积。它约占南立面宽度的18%，但为二层两户提供不穿越一层住宅的通路。

**问题是占用了好朝向，不是楼梯面积都能取消。** 将楼梯移到北部、中部或侧面之后，仍需要梯段、平台以及连接入口的公共交通。新增走道可能抵消释放的面积。

现模型另有一个重要风险：约2.3m楼梯间参考宽是否足够，应先核对实际净宽和结构，再判断能否压缩。不能为了省南向面积把楼梯做得更窄更陡。

### 现位置可以先优化的内容

- 核对南门与两户入户门附近是否存在纯空门厅，能够精简才精简。
- 梯下空间按有效净高用于清洁柜、非可燃杂物的有序收纳等适当用途；不能侵占通行，设备设置要满足相应要求。
- 公共入口开窗、玻璃门或高窗可改善明亮感，但不把公共区采光等同于卧室有效采光。
- 门扇、鞋柜、暖气与扶手统一排布，避免入口实际比图上拥堵。

## 4. 三个值得比较的方向

| 方向 | 南向收益 | 成本与布局影响 | 推荐状态 |
|---|---|---|---|
| A 保留中央楼梯，调整居住功能 | 每户南客厅可改主睡眠/老人空间，或在实测开间允许时重排南侧房间 | 对既有结构和公共动线改动较小；可能需要接受起居睡眠合用，或餐客空间重新组织 | 优先做低成本基准方案 |
| B 研究西侧或西北公共楼梯，直接从道路侧入梯 | 有机会释放南中立面，南部房间更连续 | 必须确认侧向入口条件；改变西户面积、北侧功能及二层分户平台，可能增加连廊 | 值得做一张完整平面比较，尚不能认定优于A |
| C 楼梯移入中后部，南侧保留公共走道到梯间 | 南侧大块空间可重排 | 南到梯间的走道增加公共面积，可能切断两户及中部采光；冬季采光和上下楼通风仍需解决 | 优先级低于A、B，除非入口条件明显有利 |

不把露天外楼梯作为当前首选：北方雨雪、防滑、遮蔽、冬季使用及后期封闭都会带来成本。若比较外楼梯，应比较完整的防护、屋盖、基础和边界条件，不只比较一副钢梯价格。

### A：低成本优先的功能调整（关系图，非尺寸平面）

```text
       西户低频房、储物等         东户低频房、储物等
       （居住用途需采光复核）     （居住用途需采光复核）
                  厨卫、餐区及连接口协调
       西户南向主要生活空间   公共梯   东户南向主要生活空间
       可长期睡眠/老人使用    及入口   可长期睡眠/老人使用
                         南 / 小院 / 采光最好
```

“客厅兼卧室”是经济型折中，并不等于同时拥有完整独立客厅与卧室。如果每户都需要独立南卧和独立南客厅，必须把床、沙发、通道和窗实际排出来。固定12.6m面宽扣中央公共空间后，不能仅靠在南侧画四个格子就认定可行。

### B：西侧/西北入梯的研究方向（关系图，非尺寸平面）

```text
                         北 / 邻居
 西侧道路 → 公共楼梯与平台 → 两户独立入户（需完整动线验证）
            厨卫、分户界线及连接口随之重排
            西户主要居住空间 | 东户主要居住空间
                 更多连续南向面积留给住宅
                         南 / 小院
```

图中的箭头不代表已经存在的合法门洞或已满足净宽的走道。需要比较两层实际面积，尤其要防止西户承担楼梯后过小、东户通过过长公用走廊才能入户。可接受合理的不对称，但不能未经业主确认牺牲某一户独立性。

## 5. 朝向与功能分配建议

### 南侧

至少每户保留一处长期使用的南向空间。老人、自用卧室值得优先；日间长时间起居也有价值，两者由真实居住人数与生活习惯排序。不要过早追求每户两个独立南向房而导致房间过窄。

### 北侧

优先比较低频客房、工作储物、家政和部分服务功能；具体哪些功能可换，要与厨房排烟、排污立管和两层叠合协调。既有四间北卧室可以减少或改变部分用途，房间数量不应压倒居住质量。

若仍保留北卧，应核对合法采光通风、供暖、冷桥、窗边结露和柜体布置。增加灯具能改善使用照度，但不能替代自然采光条件的复核。

### 东侧0.5m退让

把它视为有限的窗外和检修条件，不视为采光庭院或宽敞通风通道。需确认净宽、是否被邻房檐口遮挡、开窗后可操作性以及排水维护条件。厨卫增加独立可靠排风，排放位置避免邻窗与串味；外窗开启方式避免越界和碰撞。

### 西侧道路

道路一侧可能提供更好的侧向开敞，应现场比较。如果条件允许，西户起居或卧室可利用西侧采光；同时处理西晒、隐私、噪声、路面扬尘和窗外安全。不能机械地左右完全镜像后，再用装修补偿东户采光劣势。

## 6. 进深13m是否应缩短

北侧和东侧采光都差，13m进深使中部空间的有效自然采光更值得复核。建议把12m、12.5m与13m作为排布比较，而不是先认定要缩小。

- 缩短主体可能减少建造面积和中部低效空间，扩大南院。
- 但不会自动改善被邻房遮挡的北窗，也不会自动让所有房间变成南向。
- 需要保持楼梯平台、卫生间、床位及通道可用，不以压缩关键净尺寸换取账面节约。
- 长度重新分配后需保持总长19m闭合，并复核退让、邻房与院内停车。

采光井/天井不是当前第一选择：占面积，增加外墙、保温、防水和排雪维护。只有完整排布比较证明收益足够，且尺寸能形成有效采光时再采用；不能把狭窄竖井当解决深进深采光的通用办法。

## 8. 待业主选择或补充

1. 12.6m究竟为固定建筑外宽，还是包含东侧0.5m退让的地块宽度？
2. 每户实际需要几间常住卧室？是否必须同时有独立客厅与独立卧室？
3. 是否接受两户不完全镜像、面积略有差异，以换取整体采光和动线改善？
4. 西侧道路在房屋中北段能否独立开人行入口？道路宽度、门口标高和边界许可如何？
5. 北侧邻房高度与间距，一层、二层的遮挡是否相同？两层不必为了镜像而采用完全相同的居住功能。

**本轮建议：先改朝向与居住功能分配，再决定是否搬楼梯。A作为低成本比较基线，B作为释放南向面积的完整重排方案。不要只挪楼梯而不计走道，也不要为了四间北卧的数量锁死整体布局。**
