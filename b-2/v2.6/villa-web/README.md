# 自建别墅 b-2 · 3D 交互预览与空间可行性校验

基于 Blender 实测模型（`public/model.json`，531 个体块 / 191 个构件）的 Next.js 三维交互网站。
可自由浏览、错层展开、剖切，并**从几何实测计算**验证物理空间可行性（净宽 / 净高 / 踏步 / 门洞 / 家具布置 / 采光）。

## 运行

```bash
cd villa-web
npm install
npm run dev        # http://localhost:3000
# 或生产模式
npm run build && npm start
```

## 交互功能

| 功能 | 说明 |
| --- | --- |
| 视角预设 | 上帝视角 / 全楼 / 一层 / 平面 / 楼梯间 |
| 错层展示 | 爆炸展开滑块：一层原位，二层 +15.5m X 偏移，屋面 +31m X 偏移 |
| 剖切 | Y=1.2m 剖切面（对应剖面透视），实时裁剪全部材质 |
| 图层 | 一层+场地 / 二层 / 屋面 / 文字标注 / 家具占位 独立开关 |
| 两点测距 | 点击地面两点测空间距离（ESC 退出） |
| 点选构件 | 显示构件名、命中点与所在房间的校核结论 |
| 通行模拟 | 1.75m 人体（肩宽 0.44m）沿真实动线行进，实时显示头顶净空与侧向净距（不足变红） |

### URL 参数（可分享特定视图）

所有视图状态可写进地址栏直接分享，例：`?explode=100&tab=walk&furn=1`。

| 参数 | 含义 |
| --- | --- |
| `explode=0~100` | 爆炸展开比例（默认 35） |
| `f1 / f2 / roof=0` | 隐藏对应图层（默认全开） |
| `labels=0` | 隐藏文字标注 |
| `furn=1` | 显示家具占位 |
| `section=1` | 开启 Y=1.2m 剖切 |
| `tab=walk` | 打开通行模拟面板 |
| `path=p1~p4` | 预设动线（入户上楼 / 东走道 / 北端 / 东户起居） |

## 物理空间可行性校验（全部由几何实测）

- **楼梯**（从 `stair_flight_landing` 盒体反算）：踏步高 187.5mm、宽 220mm、2h+b=595mm、梯段净宽 840mm、
  平台 900×1680mm、16 级等分（8+8）、第二跑压在入口上方（进户左转即上楼，无需单独通道）
- **通行净宽**（墙盒体 z 切片反算门洞/窗洞）：入户门 1400mm、户门 900mm、卧室门 800~900mm、
  厨房门 900mm、卫生间门 800mm、楼梯间东侧走道 800mm、净高 2850mm
- **净空（3D 射线实测）**：楼梯 16 级踏面行走线净空、入户口（第二跑尾段下）、走道、户门前、二层洞口
- **家具布置后最小活动通道**（0.05m 栅格 BFS + 最大化瓶颈路径 Dijkstra）：
  每类房间按标准家具布置（双人床 1.5×2.0 / 衣柜 / 书桌 / L 形操作台 / 三件套卫生间 / 沙发餐台），
  计算从门口到每件家具使用面的最窄通道，厨房限值 0.9m、其余 0.6m
- **房间面积 / 窗地比**：窗洞面积由墙洞实测，窗地比 ≥1/7；南北对流通风校核
- **场地**：南院 5.0m、北退让 1.0m、车位 2.5×5.3m 与院深关系、影壁墙转身半径
- **改造**：楼梯间北墙 + 中墙 2 道可拆 → 两户合并（约 38m² 通宽 9.7m）可行性与结构提示

校核限值参照 GB 50096《住宅设计规范》、GB 50016《建筑设计防火规范》与人体工学经验值。

## 目录

```
lib/specs.js    房间/家具/动线规格（与 Blender 模型同一坐标系：X 东 0→12.6，Y 北 0→13，Z 上）
lib/checks.js   可行性校验计算（墙洞反算、楼梯实测、栅格净距、窗地比）
lib/scene.js    three.js 场景（盒体渲染、爆炸、剖切、射线净空、通行模拟）
pages/index.js  交互界面（控制面板 / 校验面板 / 通行模拟）
public/model.json  Blender 导出的模型数据（盒体 + 材质色 + 标签 + 分组）
```

模型数据可用 Blender MCP 重新导出（对象盒体 + `matrix_basis` + 材质 Base Color + 文字标签）。
